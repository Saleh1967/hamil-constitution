# ADR-003: SLGE عمودًا للمعرفة — قرار معلّق

## المقترح (من مراجعة الجلسة الأخرى)
جعل SLGE العمود الواحد: ط٠–ط٥، بحلقة تعلم مغلقة، ونقل `infer` وقياس الفجوة من Alghanem.

## القرار
**معلّق — لن يُنقل شيء قبل موافقة صاحب الدستور.** ما نُفّذ بلا نقل:
- SLGE-FORM (FR1–FR4): جدول الغزالي الثماني الخلايا منفَّذًا بايثون كنظير Lean المنتظر.
- tools/learning_loop.py: الحلقة موصولة بالمولّد والبوابة المحليين، وجيوبها المسمّاة (golden_eval/auto_retract) لما يصل من Alghanem.
- data/layers.json: الطبقات الست بأوسمتها + عيب الجسر المسجّل.
- TR8: وعي العيب في العنوان البتّي (ف+كسر).

## شرطان قبل أي نقل
1. الجسر سليم أو عيوبه مسجلة (الحال: عيب مسجّل لا مُصلَّح — لا نعدّل الدستور نحن).
2. حزمة وهندسة: pyproject موجود الآن؛ الحزمة `alghanem-core` قرار لاحق.
